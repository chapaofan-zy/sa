# 设备管理

---

## I/O 系统

I/O 系统由设备、控制器、通道、总线和 I/O 软件组成。设备管理的目标是提高设备利用率，为用户提供方便、统一的接口，并提高 CPU 与 I/O 设备之间的并行程度。

设备管理中常用的技术包括：中断、DMA、通道、缓冲和 SPOOLing。

## I/O 软件层次

讲义将 I/O 设备管理软件分为四层：

1. 中断处理程序
2. 设备驱动程序
3. 与设备无关的系统软件
4. 用户级软件

分层的目的，是把具体硬件差异限制在较低层，为上层提供相对统一的访问方式。

## 设备管理技术

### 通道技术

通道可以减少 CPU 对 I/O 操作的直接介入，提升主机和外设的并行程度，但仍受 CPU 管理并需要报告状态。

### DMA 技术

DMA 控制器在主存和外设之间直接传送数据，适合高速、大批量数据交换。

### 缓冲技术

通过设置缓冲区协调 CPU 和外设的速度差异，减少等待和频繁的设备操作。

### SPOOLing 技术

SPOOLing 又称外围设备联机操作。它用一种物理设备模拟另一种物理设备，使原本需要独占的设备表现为多台虚拟设备。

## 磁盘调度

磁盘调度先进行移臂调度，再进行旋转调度。由于寻道通常是访问磁盘的主要耗时部分，调度目标是减少平均寻道时间。

常见算法：

- **FCFS**：按照请求到达顺序处理。
- **SSTF**：优先处理距离当前磁头最近的磁道，但不保证平均寻道时间最短。
- **SCAN**：磁头沿一个方向扫描，到达端点后改变方向，类似电梯运行方式。
