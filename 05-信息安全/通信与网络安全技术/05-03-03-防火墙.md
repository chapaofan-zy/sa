# 防火墙

---

## 防火墙的功能

防火墙部署在内网与外网之间，通过安全策略控制网络通信，主要功能包括：

- 访问控制
- 内容控制
- 全面的日志审计
- 集中管理
- 自身的安全性和可用性
- 流量控制
- 网络地址转换（NAT）
- 虚拟专用网（VPN）

## 防火墙的分类

### 按保护层次分类

- 网络级防火墙：主要检查 IP 地址、端口和协议等网络层信息。
- 应用级防火墙：能够理解应用层协议，通常通过代理服务实现更细粒度的控制。

### 常见类型

- 包过滤型防火墙
- 电路级网关防火墙
- 应用级网关防火墙
- 代理服务器型防火墙
- 状态检测型防火墙
- 自适应代理型防火墙

## 防火墙的体系结构

### 相关组件

#### 包过滤路由器

根据 IP 地址、端口、协议等信息检查数据包，像网络边界上的门卫。

#### 堡垒主机

经过加固的主机，通常运行代理服务。外部连接先到达堡垒主机，再由堡垒主机代理访问内部服务。

#### DMZ

即非军事区或边界网络，是位于内网和外网之间的隔离子网，通常放置 Web、邮件、DNS 等对外提供服务的服务器。

### 双宿主机/多宿主机模式

```text
外网 ─── 网卡A [堡垒主机] 网卡B ─── 内网
```

防火墙主机具有两个或多个网络接口，分别连接不同的网络。通常采用代理服务，并且必须禁止主机的网络层路由功能。

通信过程为：

```text
外部用户 → 堡垒主机代理 → 内部服务器
```

数据包不能直接从一个网络接口转发到另一个网络接口，内外网通信必须经过代理控制。

### 屏蔽主机模式

```text
外网 ─── [包过滤路由器] ─── 内网
                              ├── 堡垒主机
                              └── 内部服务器
```

屏蔽主机模式由包过滤路由器和堡垒主机组成。堡垒主机安装在内网中，通常在路由器上设置规则，使其成为外部网络唯一可以直接到达的内部主机。

通信过程为：

```text
外部用户 → 包过滤路由器 → 堡垒主机 → 内部服务器
```

外部网络不能直接访问其他内部主机，路由器负责网络层过滤，堡垒主机负责代理和应用层安全。

### 屏蔽子网模式

```text
外网 ─ [外部过滤路由器] ─ DMZ ─ [内部过滤路由器] ─ 内网
                              │
                    堡垒主机、公共服务器
```

屏蔽子网模式采用两个包过滤路由器和一个堡垒主机，在内外网络之间建立一个被隔离的子网，即 DMZ。

其特点包括：

- Web、邮件、DNS 等公共服务器通常放在 DMZ 中。
- 内部网络和外部网络都可以按照规则访问 DMZ。
- 内部网络和外部网络不能借助 DMZ 直接相互通信。
- 即使 DMZ 中的堡垒主机被入侵，内部网络仍可受到内部过滤路由器的保护。
- 多个堡垒主机可以运行不同的代理服务。

### 三种体系结构对比

| 结构 | 过滤路由器 | 堡垒主机位置 | 主要特点 |
| --- | ---: | --- | --- |
| 双宿主机/多宿主机 | 通常没有 | 内外网之间 | 依靠多网卡主机和代理服务隔离内外网 |
| 屏蔽主机 | 1 个 | 内网中 | 路由器过滤网络层，堡垒主机负责代理 |
| 屏蔽子网 | 2 个 | DMZ 中 | 通过 DMZ 隔离公共服务器和内部网络 |

记忆方式：

> 双宿主机是一台堡垒主机隔开内外网；屏蔽主机是路由器加内网堡垒主机；屏蔽子网是两个路由器夹着 DMZ。

## 防火墙的局限性

1. 可能限制一些有用但存在安全缺陷的网络服务，给用户使用带来不便。
2. 对来自网络内部的攻击防护能力有限。
3. 不能防止绕过防火墙的攻击。
4. 防火墙对用户不完全透明，可能带来传输延迟、瓶颈和单点失效等问题。
5. 不能完全阻止受病毒感染的文件或软件传输。

防火墙主要解决网络边界访问控制问题，不能替代主机安全、病毒防护、身份认证和入侵检测等安全措施。
