# 安全协议

---

## SSL

SSL（Secure Sockets Layer）用于保护 Internet 上的通信安全，主要提供：

- **身份认证**：验证通信双方的合法性。
- **数据保密**：对传输数据进行加密。
- **数据完整性**：防止数据被篡改。

SSL 由以下协议组成：

- 握手协议
- 记录协议
- 警报协议

### SSL 通信过程

1. **接通阶段**：客户端向服务器发起连接请求。
2. **密码交换阶段**：客户端与服务器协商密码算法和相关参数。
3. **会话密码阶段**：双方生成本次通信使用的会话密钥。
4. **检验阶段**：客户端验证服务器获得的会话密钥。
5. **客户认证阶段**：服务器验证客户端身份或可信度。
6. **结束阶段**：双方交换连接结束信息。

## HTTPS

HTTPS 是在 HTTP 基础上结合 SSL/TLS 实现的安全通信协议。

特点：

- 对 HTTP 数据进行加密。
- 可以进行身份认证。
- 可以保证数据完整性。
- 默认使用 **443 端口**。
- HTTP 默认使用 **80 端口**。

简单记忆：

> HTTPS = HTTP + SSL/TLS

## PGP

PGP（Pretty Good Privacy）主要用于电子邮件安全，提供：

- **邮件加密**：防止未授权人员读取邮件内容。
- **数字签名**：使收件人能够确认邮件发送者身份，并验证邮件是否被篡改。

## IPsec

IPsec 是工作在网络层的安全协议体系，主要保护 IP 数据包的传输安全。

主要作用：

- 防止 IP 数据被窃听。
- 防止 IP 数据被篡改。
- 对数据进行加密和身份认证。
- 提高网络通信的安全性。
- 支持 IPv4 和 IPv6。
- 可以保护各种基于 IP 的网络流量。

## 协议对比

| 协议 | 保护对象 | 主要功能 | 常见位置 |
| --- | --- | --- | --- |
| SSL/TLS | 通信会话 | 认证、加密、完整性保护 | 传输层与应用层之间 |
| HTTPS | Web 通信 | 保护 HTTP 数据 | 应用层 |
| PGP | 电子邮件 | 邮件加密、数字签名 | 应用层 |
| IPsec | IP 数据包 | 网络层加密、认证 | 网络层 |

### 记忆口诀

> SSL/TLS 保护会话，HTTPS 保护网页，PGP 保护邮件，IPsec 保护 IP 数据包。
