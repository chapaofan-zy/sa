# UML图

## 复习要点

UML 是“统一建模语言”（Unified Modeling Language），用于用图形描述软件系统的结构、功能和运行过程。UML 不是一种固定的图，而是一组软件设计图。

UML 图通常由矩形框、椭圆、小人、实线、虚线、箭头、时间线等元素组成：

- 矩形框通常表示类、对象、组件或节点。
- 椭圆通常表示用例。
- 小人通常表示用户或外部角色。
- 实线、虚线和箭头通常表示关系、依赖或调用。
- 从上到下或从左到右通常表示流程或时间顺序。

UML 2.x 常见图可以分为三类：结构图、行为图和交互图。

### 结构图：描述系统“是什么样”

| 图 | 外观特点 | 作用 |
| --- | --- | --- |
| 类图 | 分栏矩形框，用线和箭头连接 | 描述类、属性、方法以及继承、关联等关系 |
| 对象图 | 标注 `对象名:类名` 的矩形，通过连线连接 | 展示某个时刻系统中具体对象的结构 |
| 组件图 | 组件矩形、接口和依赖线 | 描述系统由哪些模块、服务或组件组成 |
| 复合结构图 | 大框内部嵌套部件、端口和连接线 | 展示类或组件的内部组成结构 |
| 包图 | 类似文件夹的包，用依赖线连接 | 描述代码包或模块的组织和依赖关系 |
| 部署图 | 立体方框表示服务器或设备，内部放软件制品 | 描述软件部署到哪些设备、服务器或运行节点 |
| 配置文件图 | 使用 `<<profile>>`、`<<stereotype>>` 等标记 | 扩展和定制 UML，使其适合特定领域 |

### 行为图：描述系统“怎么工作”

| 图 | 外观特点 | 作用 |
| --- | --- | --- |
| 用例图 | 小人、椭圆和系统边界框 | 描述用户能够使用系统完成哪些功能 |
| 活动图 | 圆角矩形、菱形判断框、箭头和泳道 | 描述业务流程、操作流程和条件分支 |
| 状态机图 | 状态框、事件箭头、起点和终点 | 描述对象状态以及状态之间的变化 |

### 交互图：描述对象“如何通信”

| 图 | 外观特点 | 作用 |
| --- | --- | --- |
| 时序图 | 多条竖直生命线、激活条和横向消息箭头 | 描述对象按时间顺序如何调用和返回 |
| 通信图 | 对象框、连接线和编号消息 | 描述对象之间的通信关系，强调对象连接 |
| 交互概览图 | 类似活动图，节点中嵌入时序图等交互片段 | 描述多个交互过程之间的整体流程 |
| 时序约束图 | 横向时间轴、状态变化线和时间标记 | 描述实时系统中状态或数值随时间的变化 |

常见图的选择方法：

- 想知道用户能做什么：用例图。
- 想知道系统有哪些类：类图。
- 想知道业务如何流转：活动图。
- 想知道对象状态如何变化：状态机图。
- 想知道对象如何按顺序通信：时序图。
- 想知道模块如何组成：组件图。
- 想知道软件部署在哪些机器上：部署图。

类图示例：

```text
+----------------+
| User           |
+----------------+
| - name: String |
+----------------+
| + login():bool |
+----------------+
        1
        |
        *
+----------------+
| Order          |
+----------------+
| - amount: int  |
+----------------+
```

该关系表示一个用户可以有多个订单。

用例图示例：

```text
   用户
    ○
   /|\
    |
    |       (登录)
    |------  (查询订单)
    |------  (提交订单)
```

椭圆表示功能，小人表示使用功能的角色。

活动图示例：

```text
● 开始
  |
[输入账号密码]
  |
◇ 验证是否成功
 /       \\
是       否
 |        |
[进入首页] [提示错误]
  |
◎ 结束
```

活动图适合描述下单流程、请假审批流程等业务过程。

状态机图示例：

```text
[未支付] --支付成功--> [已支付]
   |                      |
   |取消                   |发货
   v                      v
[已取消]              [已发货]
```

状态机图适合描述订单、工单、审批单等对象的生命周期。

时序图示例：

```text
用户        页面        订单服务       数据库
 |           |             |             |
 |--下单---->|             |             |
 |           |--创建订单-->|             |
 |           |             |--保存------>|
 |           |             |<--成功------|
 |           |<--下单成功--|             |
```

时序图重点表示：谁先调用谁、调用顺序是什么以及返回结果是什么。

快速记忆：需求看用例，结构看类图，流程看活动，生命周期看状态，通信顺序看时序，模块组成看组件，物理部署看部署图。
