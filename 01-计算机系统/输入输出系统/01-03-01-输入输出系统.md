# 输入输出系统

---

## 输入输出工作方式

### 程序控制方式

由 CPU 执行 I/O 程序完成主机和外设之间的数据传送，包括：

- **无条件传送**：默认外设始终处于准备就绪状态，CPU 不必查询外设状态。
- **程序查询方式**：CPU 通过查询外设状态决定是否进行传送。

这种方式实现简单，但 CPU 需要参与传送控制。

### 程序中断方式

程序中断是指 CPU 执行当前程序时，遇到需要及时处理的异常情况或外部请求，暂时中止当前程序，转去处理事件，处理完成后再返回原程序继续执行。

### DMA 方式

DMA 用于主存和外设之间的高速、大批量数据交换。DMA 控制器（DMAC）负责控制传输，传输过程中 CPU 让出系统总线，由 DMAC 直接控制总线。

### 通道方式

通道是较高级的 I/O 控制部件，利用硬件和软件控制外设，减少 CPU 介入，使主机和外设可以更大程度并行工作。通道不能完全脱离 CPU，仍需要接受 CPU 的启动、停止和管理，并向 CPU 报告状态。

### I/O 处理机

I/O 处理机又称外围处理机，具有较丰富的指令系统和较完善的中断系统，专门用于大型、高效计算机系统中的外围设备 I/O 处理。

## 总线

总线是一组可供多个部件分时共享的公共信息传送线路。

### 分类

- 按功能：地址总线、数据总线、控制总线。
- 按位置：内部总线、外部总线，或机内总线、机外总线。
- 按功用：局部总线、系统总线、通信总线。
- 按数据线数量：并行总线、串行总线。

总线标准规定不同厂家生产的部件需要遵守的接口要求，以便实现部件互换。

### 性能指标

- **总线宽度**：总线的线数，直接影响地址线和数据线数量。
- **总线带宽**：单位时间传输的字节数。讲义给出的简化关系为：`总线带宽 = 总线宽度 x 总线频率`。
- **总线负载**：总线上允许连接的最大设备数量。
- **分时复用**：不同时段使用同一信号线传送不同信号。
- **猝发传输**：一个总线周期内连续传输多个地址相邻的数据。

讲义示例中，一个总线周期传输 4B，占用 2 个 10MHz 时钟周期，则总线周期为 0.2 微秒，带宽为 `4 / 0.2 = 20MB/s`。

## I/O 接口

I/O 接口也称 I/O 控制器，用于实现主机和外设之间的信息交换。主要功能包括：

1. 实现主机和外设的通信联络控制。
2. 地址译码和设备选择。
3. 数据缓冲。
4. 数据格式变换。
5. 传递控制命令和状态信息。

### 串行通信

- **异步通信**：字符之间的时间间隔可以任意，需要在字符开始和结束处加入开始位、停止位。设备简单、成本较低，但传输效率较低。
- **同步通信**：收发双方使用同频同相的同步时钟，在报文开始处加入同步字符，然后按同步时钟逐位传送。

### 常见接口和编址

讲义列举了 IDE、EIDE、ATA 等磁盘接口，并提到 I/O 端口可以采用独立编址或统一编址（存储器映射）。

## 经典题提示

DMA 传输中，CPU 通常负责传输前的初始化和传输后的处理，具体数据传送由 DMA 控制器直接完成。因此“每传输一个数据都需要 CPU 执行指令”与 DMA 的工作方式不符。
