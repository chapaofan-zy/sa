# 主存与辅存

---

## 主存储器

主存又称内存，用于存放计算机运行时的程序和数据，并能由 CPU 直接读写。讲义将主存分为 RAM 和 ROM。

### RAM

RAM 可以读出和写入，但断电后信息通常不能保存，因此主要用于暂存数据。

- **DRAM**：存储信息会随时间逐渐消失，需要定时刷新。
- **SRAM**：在不断电的情况下可以保持信息，不需要像 DRAM 那样定时刷新。

### ROM

ROM 的内容主要用于随机读出，写入后即使断电也不会丢失。讲义在此处采用“只能读出、不能写入”的概括性描述，具体 ROM 类型的写入方式不在本讲义范围内。

## 辅助存储器

### 磁带

磁带由磁带机及其控制器组成，是一种顺序存取设备。顺序存取意味着访问某个位置时通常要沿磁带依次移动到目标位置。

### 机械硬盘

机械硬盘由磁性盘片、驱动系统、读写系统和控制系统组成。磁盘上的信息组织层次包括：

`记录面 -> 圆柱面 -> 磁道 -> 扇区`

存储容量可按讲义公式计算：

```text
存储容量 = n x t x s x b
```

其中：

- `n`：总记录面数
- `t`：每面的磁道数
- `s`：每道的扇区数
- `b`：每个扇区存储的字节数

磁盘访问通常涉及寻道、旋转等待和数据读写三个部分。讲义指出读写时间相对较快，可以忽略，但同页给出的“磁盘存取时间=等待时间+读写操作时间”没有明确是否包含寻道时间，前后表述存在不一致，**待验证**。

### 固态硬盘与混合硬盘

- **SSD**：由闪存芯片、主控和缓存组成，寻道时间可以忽略，读取速度较快，但价格较高。
- **SSHD**：结合机械硬盘和固态存储，使用容量较小的闪存保存常用文件，以减少寻道并提升读写效率。

## RAID

廉价磁盘冗余阵列（RAID）用于缩小 CPU 处理速度与磁盘存储速度之间的差距，也可以通过冗余提高数据可靠性。讲义列举的级别如下：

| 级别 | 讲义中的主要特征 | 记忆重点 |
| --- | --- | --- |
| RAID0 | 无冗余、无校验，数据分块存放 | 性能和空间利用率高，但故障率高 |
| RAID1 | 磁盘镜像 | 安全性高，空间利用率约为 50% |
| RAID2 | 使用海明码纠错 | 通过校验盘提供纠错和检错 |
| RAID3/4 | 奇偶校验码放在独立校验盘 | 一个盘失效时可用异或恢复数据 |
| RAID5 | 奇偶校验信息分布在组内所有磁盘 | 没有独立校验盘 |
| RAID6 | 数据盘和分布式校验方案 | 讲义另描述了专用异步校验盘，具体表述待核验 |
| RAID7 | 强调异步高 I/O 速率和高传输率 | 讲义称其为高档次阵列 |
| RAID10 | RAID0 与 RAID1 的组合 | 同时关注性能和可靠性 |
