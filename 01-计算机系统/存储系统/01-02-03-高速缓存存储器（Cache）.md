# 高速缓存存储器（Cache）

---

## 基本原理

使用 Cache 改善系统性能的依据是程序的局部性原理。

### 时间局部性

如果一个存储单元刚被访问，那么该单元可能很快再次被访问。

### 空间局部性

如果一个存储单元刚被访问，那么与它相邻的单元也可能很快被访问。

根据局部性原理，可以把当前常用或即将使用的信息预先放入 Cache。CPU 访问数据时：

1. 先在 Cache 中查找。
2. 如果找到，直接从 Cache 读取。
3. 如果没有找到，再从主存读取，并将数据同时送往 CPU 和 Cache。

## 地址映射

主存和 Cache 都划分为容量相同的块。CPU 发出访存请求后，地址先送到 Cache 控制器，用于判断所需数据是否已经在 Cache 中。

### 全相联映射

主存的每一块可以映射到 Cache 的任意块。它的映射灵活，但需要比较的位置较多，讲义强调其速度较慢。

### 直接映射

一个主存块只能映射到 Cache 的一个特定位置。硬件电路比较简单，但映射关系固定，灵活性较低。

### 组相联映射

组相联映射是全相联映射和直接映射的折中：

- 先用直接映射确定组号。
- 再在对应组内用全相联方式确定具体块。

## 替换算法

当 Cache 已满而新数据需要装入时，必须淘汰部分旧数据。讲义列举三种常用算法：

- **随机算法**：随机选择要替换的块。
- **先进先出（FIFO）**：优先替换最早进入 Cache 的数据。
- **近期最少使用（LRU）**：优先替换最近一段时间使用最少的数据。

## 计算题提示

组相联映射题通常要依次确定：

1. 组数：`Cache 块数 / 每组块数`。
2. 每个主存页或块的大小：通常与 Cache 块大小一致。
3. 主存地址位数：由主存容量和编址单位决定。
4. 组号位数：由组数决定。

题目中的“字”“字节”“页”“块”是不同的计量单位，计算前要先统一编址单位。
