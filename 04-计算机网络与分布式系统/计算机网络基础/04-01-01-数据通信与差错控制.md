# 数据通信与差错控制

---

## 数据通信模型

数据通信过程可以抽象为：

```text
信源 -> 发送设备 -> 信道 -> 接收设备 -> 信宿
```

- **信源**：产生原始信息，例如人说话、传感器数据。
- **发送设备**：把信息转换成适合传输的信号，例如编码、调制。
- **信道**：传输信号的媒介，例如光纤、电缆和无线电波。
- **接收设备**：从信道接收信号并还原信息，例如解调、解码。
- **信宿**：信息的最终接收者，例如听筒或电脑屏幕。
- **噪声**：传输过程中来自外界的干扰。

模拟数据随时间连续变化，数字数据取有限个离散值。

## 带宽与传输速率

### 码元速率

一个数字脉冲称为一个码元。码元速率表示单位时间内信号波形变化的次数，单位是波特（Baud）。若码元宽度为 T 秒，则：

```text
B = 1 / T
```

### 奈奎斯特定理

若数字信道带宽为 W，则最大码元速率为：

```text
B = 2W Baud
```

这个公式关注的是无噪声条件下的最大码元速率。

### 香农定理

有噪声信道的极限数据速率为：

```text
C = W log2(1 + S/N)
```

其中 W 是信道带宽，S 是信号平均功率，N 是噪声平均功率，S/N 是信噪比。信噪比也可用分贝表示：

```text
dB = 10 log10(S/N)
```

### 误码率

误码率表示传输二进制位时发生错误的概率。讲义写作“低于 10^-9，即平均每传送 1Mb 才允许错 1b”，数量级换算前后不一致，**待验证**。

## 数据编码

### 模拟数据编码

- **调幅（AM）**：用载波有无表示不同数字信号。
- **调频（FM）**：用频率变化表示不同数字信号。
- **调相（PM）**：用相位变化表示不同数字信号。

### 数字数据编码

- **不归零编码**：低电平表示 0，高电平表示 1。
- **曼彻斯特编码**：用每个比特中的电平跳变表示数据。
- **差分曼彻斯特编码**：每比特开始处无跳变表示 1，有跳变表示 0。

## 差错控制

### 码距

从一个编码变为另一个编码所需要改变的位数称为码距。码距越大，通常越有利于检错和纠错。

### 奇偶校验码

增加一位校验位，使编码中 1 的个数保持奇数或偶数。奇偶校验可以检查单个位错误，但不能纠错。

### 海明码

海明码在数据位之间的指定位置插入校验位，通过扩大码距实现检错和纠错。数据位为 n 位、校验位为 k 位时，讲义给出的关系为：

```text
2^k - 1 >= n + k
```

### CRC

CRC 只能检错，不能纠错。通信双方需要约定相同的生成多项式 `G(x)`。

基本过程：

1. 生成多项式的最高位和最低位必须为 1。
2. 原始信息后补 r 个 0，r 是生成多项式的阶。
3. 把生成多项式转换为二进制除数。
4. 用模 2 除法计算余数。
5. 将余数补足 r 位后追加到原始信息末尾。
6. 接收方用同一生成多项式相除，余数为 0 表示按该校验规则未发现错误，否则请求重传。

讲义例题：原始信息 `10110`，生成多项式 `x^4 + x + 1`，除数为 `10011`，最终给出的发送串为 `101101111`。
