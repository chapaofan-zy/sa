# TCP/IP 协议簇

---

## 四层模型

TCP/IP 协议簇由下至上分为：

1. 网络接口层
2. 网际层
3. 传输层
4. 应用层

### 应用层

直接与用户交互，提供电子邮件、文件传输和网络管理等服务。

### 传输层

对应用层数据进行分段，并加入必要控制信息。主要协议是 TCP 和 UDP。

### 网际层

把传输层信息封装为 IP 数据报，填写地址信息并选择发送路径。

### 网络接口层

也称链路层，负责接收和发送数据报，并与网络传输媒介交互。

## 与 OSI 的对应

TCP/IP 的应用层大致对应 OSI 的应用层、表示层和会话层；TCP/IP 的网络接口层覆盖 OSI 的数据链路层和物理层；网际层与 OSI 网络层对应，传输层保持对应关系。

## 主要协议

### IP

IP 数据报由首部和数据两部分组成。讲义介绍的基本首部固定为 20 字节，另有 0-40 字节可变长度选项。常见字段包括版本号、总长度、生存期、上层协议、首部校验和、源地址、目的地址和用户数据。

### ICMP

ICMP 与 IP 同属网络层，用于传递通信问题信息，例如数据报无法到达、路由器缓存不足，或向发送主机提供路径信息。

### TCP

TCP 提供面向连接的可靠传输。讲义重点介绍标志字段和窗口字段：

- `URG`：紧急指针有效。
- `ACK`：确认序号有效。
- `PSH`：推进功能有效。
- `RST`：连接复位。
- `SYN`：同步序号，用于建立连接。
- `FIN`：数据发送完成，可以释放连接。
- **窗口**：用于流量控制。

### UDP

UDP 提供无连接传输服务，不保证可靠性和顺序，但协议开销较少，适用于部分网络管理和实时性要求较高的场景。UDP 在 IP 基础上增加端口寻址功能。

### ARP 与 RARP

- **ARP**：把 IP 地址转换为物理地址。
- **RARP**：把物理地址转换为 IP 地址。

### 应用层协议

讲义列举 NFS、Telnet、SMTP、DNS、SNMP 和 FTP 等应用层协议。
